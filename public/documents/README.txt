This directory holds sample/placeholder downloadable documents referenced by
product detail pages (e.g. axm-400-datasheet-demo.pdf).

For this portfolio demo build, no real PDF binary is generated by the build
process itself. Before deploying this site for real use, replace the
referenced datasheet path in src/content/products/axm-400.md with an actual
PDF asset placed in this directory.

See docs/ASSET_LICENSES.md for the current placeholder status of all
downloadable assets referenced across the site.
