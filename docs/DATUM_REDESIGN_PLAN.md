Tracking document for the CC-00 → CC-10 redesign pass defined in
`docs/redesign/forgeon_claude_code_redesign_tasks.md`, decision background in
`docs/redesign/forgeon_full_audit_and_redesign.md`.

Direction is fixed: **Precision Datum System／製程座標系**. This plan is not
re-litigated per stage — only execution status is updated here.

## Non-negotiables carried from the task book

- Astro + TypeScript stays; no React/Vue/Next without prior justification and approval.
- No `higgsfield-websites`, ever.
- No fabricated real clients, factories, staff, certifications, revenue, rankings.
- Paid Higgsfield generation requires explicit user approval before any call — capped
  at 13 assets total in round one (3 hero, 6 product, 4 industry). See
  `docs/DATUM_ASSET_PLAN.md` (created in CC-01/CC-02 when asset needs are concrete).
- Each stage ends with a stop-and-report checkpoint; no stage proceeds into the next
  without that checkpoint being delivered.
