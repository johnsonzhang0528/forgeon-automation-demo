# CC-02F-02 — Locale preview routes (real getStaticPaths)

## Goal

Move from CC-02's "one page renders both languages, client JS toggles
visibility" pattern to real, per-locale static routes.

## Scope

`src/pages/internal-preview/cc02-final/[locale].astro` using
`getStaticPaths()` to output exactly:

```
/internal-preview/cc02-final/zh-tw/
/internal-preview/cc02-final/en/
```

Each page:
- Server-renders ONLY its own language — no hidden duplicate DOM block for
  the other locale, no client-JS whole-page text toggle.
- Correct `<html lang="zh-Hant-TW">` / `<html lang="en">`.
- Exactly one real `<h1>`.
- Language switch is a real route `<a href="/internal-preview/cc02-final/
  en/">` / `.../zh-tw/` link — not a JS-driven visibility toggle.
- `<meta name="robots" content="noindex, nofollow">`.
- Excluded from `sitemap.xml` (naturally true — `sitemap.xml.ts` only
  enumerates real content-collection routes, never scans `src/pages`).
- Not in production nav (`src/config/nav.ts` untouched).
- No analytics wiring (`AnalyticsBridge` not imported).

The historical `variant-a.astro`/`variant-b.astro`/`variant-c.astro` files
under `cc02-hero/` are left completely untouched — they remain as
historical comparison artifacts, not upgraded into "the final version."

## Acceptance criteria

- [ ] `astro build` emits exactly `dist/internal-preview/cc02-final/zh-tw/
      index.html` and `dist/internal-preview/cc02-final/en/index.html`.
- [ ] Each built HTML file has exactly one `<h1>` and correct `<html lang>`.
- [ ] Each built HTML file has `<meta name="robots" content="noindex,
      nofollow">`.
- [ ] `dist/sitemap.xml` (generated by `sitemap.xml.ts`) never mentions
      `internal-preview`.
- [ ] `cc02-hero/variant-{a,b,c}.astro` have zero diff from `CC02F_BASE`.
